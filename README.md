# Pontiq

AI app for school that

## Development

Use Node 24 (`nvm use`) and Bun 1.3.5. SvelteKit requires Node 22.17 or newer.

```sh
bun install
bun run dev
```

Run `bun run check`, `bun run lint`, and `bun run build` to validate changes.
